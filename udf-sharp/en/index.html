UDF# Privacy Policy

Last updated: September 21, 2026

UDF# is a Windows desktop utility application. This policy explains how the application handles personal data.

1. Data collection

UDF# does not require a user account, display advertisements, or use analytics or tracking to collect personal information about application usage.

UDF# does not send user files, document contents, or personal information to a server controlled by the developer.

2. Documents and local processing

UDF# processes DOC, DOCX, RTF, UDF, PDF, and EYP files on the user's computer. Conversion, text replacement, and EYP extraction are performed locally.

The user is responsible for the contents of files processed with the application. Backing up important documents before processing is recommended.

3. Internet connectivity

The core document-processing functions do not require an online account or cloud storage. If a future version introduces an online feature, the relevant data processing will be disclosed separately.

4. Third-party services

UDF# does not sell or rent personal data to third parties for advertising or analytics purposes. UDF# is not responsible for data-processing practices of the operating system, antivirus software, cloud storage, or other third-party software used by the user.

5. Children's privacy

UDF# is not designed to collect personal information from children or target a particular age group for data collection.

6. Changes to this policy

This policy may be updated if the application's functionality or data-processing practices change.

7. Contact

For privacy questions or requests, please use the GitHub repository.
